**Определение** последовательность $\{x_{n}\}$ наз-ся фундаментальной, если
$\forall \varepsilon > 0 \ \exists N: \forall n,m \ge N \quad |x_{n}-x_{m}| < \varepsilon$
или
$\forall \varepsilon > p \ \exists N: \forall n \ge N \ \forall p \ge 1 \quad |x_{n+p} -x_{n}| < \varepsilon$ 

# Теорема
**формулировка** если $\exists \lim_\limits{n\to \infty} x_{n}= a \in \mathbb{R}$, то $\{x_{n}\}$ - фундаментальна (в обратную сторону также работает)

### Доказательство

$\to$ $\exists \lim_\limits{n\to \infty} x_{n}= a \in \mathbb{R}$
пусть $\varepsilon > 0$ произвольный, тогда
$\exists N$ $\forall n > N$ $|x_{n}-a| < \frac{\varepsilon}{2}$
тогда $\forall m,n > N$ $|x_{n}- x_{m}| = |x_{n}- x_{m} + 0| = |x_{n} - x_{m} + a - a| = |x_{n} - a - x_{m} + a| \le |x_{n} -a| + |-x_{m} + a| = |x_{n} -a| + |x_{m} - a| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon$ т.е. $\{x_n\}$ сходится
$\leftarrow$ пусть $\varepsilon = 1$ 
тогда $\exists N_{\varepsilon} \ \forall m, n \ge N_{\varepsilon}$. Зафиксируем $m = N$, тогда $\forall n \ge N$ 
$|x_{n} - x_{N}| < 1$
$|x_{n}| = |x_{n} + 0| = |x_{n} - x_{N} + x_{N}| \le |x_{n} - x_{N}| + |x_{N}| < |x_{N}| + 1$
$M = max(|x_{1}|, |x_{2}|, \dots, |x_{N}| + 1)$ 
тогда $\forall n \ge N \quad |x_{n}| \le M$ 
По [[11. Лемма Больцано-Вейерштрасса о сходящейся подпоследовательности. Теорема Вейерштрасса о частичных пределах#Лемма Больцано-Вейерштрасса]] из $\{ x_n\}$ можно выделить подпоследовательность, такую, что $\{x_{n_{k}}\}$ 
 $\lim_\limits{k\to \infty} x_{n_{k}} = a \in \mathbb{R}$. Тогда $\{x_{n_{k}}\}$  фундаментальна, тогда 
 $\forall \varepsilon > 0 \ \exists n': \forall n,m > n' \quad |x_{n} - x_{m}| < \frac{\varepsilon}{2}$ 
 $\exists k: \forall n_{k} \ge n' \quad |x_{n_{k}} - a| < \frac{\varepsilon}{2}$ 
 тогда для всех $n > n'$
 $|x_{n}-a| = |x_{n} - a + 0| = |x_{n} - a + x_{n_{k}} - x_{n_{k}}| = |x_{n} - x_{n_{k}} + x_{n_{k}} - a| \le |x_{n} - x_{n_{k}}| + |x_{n_{k}} - a| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon$
