# Предел последовательности
*Опр.* Число $A$ называется пределом последовательности {$x_{n}$}, если $\forall \varepsilon > 0 \ \exists N_{\varepsilon}: \forall n > N_{\varepsilon}: \quad |x_{n} - A| < \varepsilon$

# Произведение бесконечно малой и ограниченной последовательности
*Опр.* последовательность называется бесконечно малой, если её предел равен 0

формулировка: если $\lim_\limits{n \to \infty} x_n = 0$ и $\{y_n\}$ - ограниченная последовательность, то $\lim_\limits{n \to \infty} x_n y_n = 0$ 
Доказательство:
	Пусть $|y_n| \leq M, M > 0$, тогда по определению предела $\forall \varepsilon > 0 \ \exists N \ \forall n > N: |x_n| < \varepsilon$,
	возьмём $\varepsilon = \frac{\varepsilon}{M}$, тогда $|x_n| < \frac{\varepsilon}{M}$, рассмотрим:
	$|x_n y_n| < \frac{\varepsilon}{M} M$
	$|x_n y_n| < \varepsilon$
	что равносильно, тому, что $\lim_\limits{n \to \infty} x_n y_n = 0$    

# Обратная величина к бесконечно малой
формулировка: обратная величина к бесконечно малой это бесконечно большая.
$\lim_\limits{n \to \infty} |x_n| = 0$, то $\lim_\limits{n \to \infty} \frac{1}{|x_n|} = \infty$ 
Доказательство
	 $\lim_\limits{n \to \infty} |x_n| = 0$, пусть $\forall \varepsilon > 0$, $\varepsilon$ - произвольный, тогда $\varepsilon = \frac{1}{M}$,
	 по определению предела $\exists N: \forall n > N: |x_n| < \varepsilon$, тогда
	 $|x_n| < \frac{1}{M} \quad M < \frac{1}{|x_n|}$, другими словами  $\lim_\limits{n \to \infty} \frac{1}{|x_n|} = \infty$ 
(навсякий случай, мы берём $x_n \ne 0$ )
