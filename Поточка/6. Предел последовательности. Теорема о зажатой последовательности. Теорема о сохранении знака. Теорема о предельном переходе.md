# Предел последовательности
*Опр.* Число $A$ называется пределом последовательности {$x_{n}$}, если $\forall \varepsilon > 0 \ \exists N_{\varepsilon}: \forall n > N_{\varepsilon}: \quad |x_{n} - A| < \varepsilon$ 

# Теорема о зажатой последовательности
(ака лемма о двух полицейских)
*Формулировка* {$x_n$},{$y_n$},{$z_n$}, и $\forall n: x_n \le y_n \le z_n$, и $\lim_\limits{n \to \infty} x_n = \lim_\limits{n \to \infty} z_n = a \in \mathbb{R}$ , то $\exists\lim_\limits{n \to \infty} y_n = a$ 
Доказательство:
	$\forall \varepsilon > 0 \ \exists N_1: \forall n > N_1 \quad |x_n - a| < \varepsilon$
	$\forall \varepsilon > 0 \ \exists N_2: \forall n > N_2 \quad |z_n - a|< \varepsilon$ 
	возьмём $N = max{N_1,N_2}$
	тогда $a - \varepsilon < x_n < z_n < a + \varepsilon \to a - \varepsilon < x_n \le y_n \le z_n < a + \varepsilon$ , т.е
	 $a - \varepsilon < y_n < a + \varepsilon$, $-\varepsilon < y_n - a <  \varepsilon$, другими словами $|y_n - a| < \varepsilon$

# Теорема о сохранении знака

Уточнить у Пупышева
формулировка:
Если существует предел последовательности $\{x_n\}$, равный $A$, то если, $A > 0$, то существует $N$ такое, для любых $n$ больше $N$ $x_n > 0$ 
иная формулировка:
$\exists \lim_\limits{n \to \infty} x_n = A > 0 \to \exists N: \forall n > N \quad x_n > 0$ 
Доказательство:
$A \in \mathbb{R}_{>0}$ тогда возьмём произвольный $\varepsilon = \frac{A}{2} > 0$ 
По определению $\forall \varepsilon > 0 \ \exists N: \forall n > N \quad |x_n - A| < \varepsilon$ 
$A - \varepsilon < x_n < A + \varepsilon$ р-м левую часть
$A - \varepsilon < x_n$ 
$A - \frac{A}{2} < x_n$
$0 < \frac{A}{2} < x_n$
$0 < x_n$ 
начиная с некоторого $N$, $x_n > 0$ 

# Теорема о предельном переходе
вспомогательное утверждение
	Если существует предел последовательности $\{x_n\}$, равный $A$, то если, $A > \alpha$, то существует $N$ такое, для любых $n$ больше $N$ $x_n  > \alpha$ 
	Доказательство:
		возьмём $\varepsilon = \frac{A - \alpha}{2}$ 
		По определению $\forall \varepsilon > 0 \ \exists N: \forall n > N \quad |x_n - A| < \varepsilon$ 
		$A - \varepsilon < x_n < A + \varepsilon$ р-м левую часть
		$A - \varepsilon < x_n$ 
		$\frac{A+\alpha}{2} < x_n$ 
		$\frac{A+\alpha}{2} > \alpha$
