# Индуктивные множества
*Опр.* Множество $X \subset \mathbb{R}$ называется индуктивным, если $\forall x \in X: \ x + 1 \in X$ 

*Замечание* пересечение любой совокупности индуктивных множеств является индуктивным множеством.
## Доказательство:
Пусть {$x_{\alpha}$}- семейство индуктивных множеств. Пусть  $X = \bigcap_\limits{\alpha \in A} x_{\alpha}$ ($A$ - множество индексов).
Пусть $x \in X = \bigcap_\limits{\alpha \in A} x_{\alpha}$ , тогда $\forall \alpha \in A: \ x \in x_{\alpha}$ т.к. все множества индуктивные из этого следует, что $x+1 \in X = \bigcap_\limits{\alpha \in A} x_{\alpha}$ 
*Опр.* Множеством натуральных чисел $\mathbb{N}$ называется наименьшее индуктивное множество содержащее 1. Другими словами, $\mathbb{N}$ - пересечение всех индуктивных множеств, содержащих 1.

# Математическая индукция
Если $E \subset \mathbb{N}$ такое, что
1)$1 \in E$
2)$\forall n \in E, \ n + 1 \in E \to E = \mathbb{N}$ 
Доказательство
	из 2) оно индуктивно, причём содержит 1. Из этого следует, что $E$ индуктивное множество и содержит 1. По определению множества $\mathbb{N}$ - пересечение всех индуктивных множеств, содержащих 1, то $\mathbb{N} \subset E \to \mathbb{N} = E$

# Бином-Ньютона
## свойства $C_{n}^k$:
Определим $n! = 1 * 2 * 3 * \dots * n$, $С_n^k = \frac{n!}{k!(n-k)!}$ 
1)$C_{n}^k = C_{n}^{n-k}$ доказательство тривиально
2)$C_{n}^k + C_{n}^{k-1} = C_{n+1}^k$
док-во (2)
$C_{n}^k + C_{n}^{k-1} = \frac{n!}{k!(n-k)!} +\frac{n!}{(k-1)!(n-k + 1)!} = \frac{n!(n-k+1) +n!k}{k!(n-k+1)!} = \frac{(n+1)!}{k!(n+1-k)!} = C_{n+1}^k$

## Доказательство по индукции
Пусть $E = \{ n \in \mathbb{N} |\ (x+y)^n= \sum_{k=0}^{n} C_{n}^{k}x^{n-k}y^{k}\}$ 
1) База индукции, проверим для 1:
 $(x+y)^1= x + y$ - верно $1 \in E$
 
 2) Предположение индукции, допустим, что для $n$ верно:
$(x+y)^n= \sum_{k=0}^{n} C_{n}^{k}x^{n-k}y^{k}$ - $n \in E$

3) Докажем, что для $n+1$ верно:
$(x+y)^{n+1} = (x+y)^{n}(x+y) =(x+y)\sum_{k=0}^{n} C_{n}^{k}x^{n-k}y^{k} = \sum_{k=0}^{n} C_{n}^{k}x^{n-k+1}y^{k} + \sum_{k=0}^{n} C_{n}^{k}x^{n-k}y^{k + 1}$ 

пусть $k + 1 = m; \ 1 \leq m \leq n + 1 \quad k = m-1$ во второй сумме
