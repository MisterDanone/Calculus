Если последовательность возрастает (убывает) и она ограничена  сверху (снизу), то она имеет конечный предел
пусть $\{x_n \}$ - наша последовательность
## возрастает
Если она ограничена сверху, тогда $\exists supA = a$, тогда $\forall \varepsilon > 0 \ \exists N: \forall n > N: a - \varepsilon < x_n$
но по определению $supA$ верно следующее $x_n \le a < a + \varepsilon$, $\forall \varepsilon >0$ 
объединим 2 неравенства
$a - \varepsilon < x_n \le a < a + \varepsilon$
$a - \varepsilon < x_n < a + \varepsilon$ 
другими словами
$\forall \varepsilon > 0 \ \exists N: \forall N > n \quad |x_n - a| < \varepsilon$ 
## убывает
Если она ограничена снизу, тогда $\exists infA = a$, тогда $\forall \varepsilon > 0 \ \exists N: \forall n > N \newline x_n < a + \varepsilon$ 
по определению инфимума: $a \le x_n$, тогда
$\forall \varepsilon > 0 \newline a - \varepsilon < x_n < a + \varepsilon \ равносильно \newline \forall \varepsilon > 0 \ \exists N: \forall n > N \quad |x_n - a| < \varepsilon$
