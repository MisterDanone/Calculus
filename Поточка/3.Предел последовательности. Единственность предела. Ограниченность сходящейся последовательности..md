# Единственность предела
пусть последовательность {$x_{n}$} имеет предел равный $a$, и предел равный $b$, т.е.
$\lim_\limits{n \to \infty}x_{n} = a,\lim_\limits{n \to \infty}x_{n} = b$ , $a < b$ (конечные)
Доказательство:
	р-м произвольный $\epsilon > 0$, пусть $\epsilon = \frac{|b-a|}{2} >0$
	$\exists N_{1} \ \forall n > N_{1}: |x_{n}-a|< \epsilon$
	$\exists N_{2} \ \forall n > N_{2}: |x_{n}-b|< \epsilon$
	возьмём $N = max\{N_{1},N_{2}\}$, р-м
	$|a-b| = |a  - b + 0| = | a - b + x_{n} - x_{n}|$
	$|a - x_{n} + x_{n} - b|\leq |a - x_{n}| + |x_{n} - b| =|a - x_{n}| + |b -x_{n}|$
	$|a - x_{n}| + |b -x_{n}| < \epsilon + \epsilon = 2\epsilon = |b-a|$
	$\to |a-b|<|b-a| \to$ противоречие, предел единственен
	
# Ограниченность сходящейся последовательности
Формулировка: Сходящаяся последовательность ограничена, другими словами, $\exists \lim_\limits{n \to \infty}x_{n}=a \in \mathbb{R} \to  \exists M > 0: \forall n \quad |x_{n}| \leq M$ .
Доказательство:
	Пусть $\epsilon = 1$, тогда $\exists N_{\epsilon}: \forall n > N_{\epsilon} \quad |x_{n} -a| < 1$ из этого можем полагать, что
	$\forall n > N_{\epsilon} \quad |x_{n}| = |x_{n} + 0| =|x_{n} - a + a| \leq |x_{n} - a| + |a| < |a| + 1$ 
	Пусть $M = max\{|x_1|,\dots, |x_{N_{\epsilon}}|, |a| +1 \}$ 
	$\forall n \in \mathbb{N}: |x_{n}| \leq M$
