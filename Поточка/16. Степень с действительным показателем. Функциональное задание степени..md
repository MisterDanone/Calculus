# Функциональное задание степени
**формулировка** $\forall a > 0$ существует функция $f_{a}: \mathbb{R} \to \mathbb{R}$ удовлетворяющая следующим условиям:
1) $f_{a}(x+y) =f_{a}(x) f_{a}(y)$ 
2) $f_{a}(x)$ - монотонна
3) $f_{a}(1) = a$
Обозначим $f_{a}(x) = a^{x}$ для $x \in \mathbb{R}$

**Опр** Функция монотонна, если $\forall x_1, x_2: x_1 < x_2 \quad f(x_{1}) \le f(x_{2})/ f(x_{1}) \ge f(x_{2})$ 
Доказательство:
1) р-м $a = f_{a}(1)$, тогда
$a = f_{a}(1) = f_{a}(1+0) = f_{a}(1) f_{a}(0) = af_{a}(0)$
отсюда, $f_{a}(0) = 1$. Рассмотрим $x > 0$
$f_{a}(0) = f_{a}(x-x) = f_{a}(x) f_{a}(-x)$ 
отсюда $f_{a}(-x) = \frac{1}{f_{a}(x)}$. Т.е. значения функции на отрицательных числах определяются черех значения функции на положительных числах однозначно
2) Рациональные значения
$\frac{1}{n}: n \in \mathbb{N}$
 $a = f_{a}(1) = f_{a}\left(\frac{1}{n} + \dots + \frac{1}{n}\right)= f_{a}\left(\frac{1}{n}\right)\dots f_{a} (\frac{1}{n}) = f_{a} (\frac{1}{n})^{n}$ 
 $\frac{m}{n} \ m,n \in \mathbb{N}$
  $a = f_{a}(1) = f_{a}\left(\frac{1}{n} + \dots + \frac{1}{n}\right)= f_{a}\left(\frac{1}{n}\right)\dots f_{a} (\frac{1}{n}) = f_{a} (\frac{1}{n})^{m} = a^\frac{m}{n}$ 
  аналогично с $-\frac{m}{n}$ 
  $f_{a}\left(- \frac{m}{n}\right)= \frac{1}{f_{a}(\frac{m}{n})} = a^\frac{-m}{n}$ 
  $a = 1 \ \forall n \quad f_{a}(n) = 1$
  $a > 1 \ \forall n \quad f_{a}(n)$ возрастает
  $1>a>0 \ \forall n \quad f_{a}(n)$ убывает
3) Иррациональные значения
пусть $r \notin \mathbb{Q}$ тогда пусть
$A = \{f_{a}(q)| q\in Q, q < r\}, \ B =\{f_{a}(q)| q\in Q, q > r\}$ 
для монотонности $f_{a}$ необходимо:
$\sup A \le f_{a}(r) \le \inf B$ 
покажем, что $\sup A = \inf B$. Фиксируем $n \in \mathbb{N}$, тогда существует единственное $m\in \mathbb{Z}$, что $\frac{m}{n} \le r < \frac{m+1}{n}$ 
тогда 
$\sqrt[n]{a^{m}} \le \sup A \le \inf B \le \sqrt[n]{a^{m+1}} = \sqrt[n]{a^{m}} \sqrt[n]{a}$ 
тогда
$\sup A \le \inf B \le \sup A \sqrt[n]{a}$ 
поскольку $\lim_\limits{n\to\infty} \sqrt[n]{a} = 1$, то
$\sup A = \inf B$
тогда
$\sup A \le f_{a}(r) \le \inf B = \sup A$ 
т.е. $f_{a}(r) = \sup A$
