# Арифметические свойства верхнего и нижнего предела последовательности

## Сложение
**формулировка** $\overline{\lim_\limits{n\to\infty}} (x_{n} + y_{n}) \le \overline{\lim_\limits{n\to\infty}} x_{n} + \overline{\lim_\limits{n\to\infty}} y_{n}$  
доказательство:
$\forall k \newline \forall n \ge k \quad x_{n} \le \sup_\limits{m\ge k} x_{m} \newline \forall n \ge k \quad y_{n} \le \sup_\limits{m\ge k} y_{m}$  
сложим
$x_{n} + y_{n} \le \sup_\limits{m\ge k} x_{m} + \sup_\limits{m\ge k} y_{m} \rightarrow \sup_\limits{n\ge k}({x_{n} + y_{n}}) \le \sup_\limits{m\ge k} x_{m} + \sup_\limits{m\ge k} y_{m}$  

$\lim_\limits{k\to\infty} (\sup_\limits{n\ge k}({x_{n} + y_{n}}) ) \le \lim_\limits{k\to\infty} \sup_\limits{m\ge k} x_{m} + \lim_\limits{k\to\infty} \sup_\limits{m\ge k} y_{m}$ 
по определению
$\overline{\lim_\limits{n\to\infty}} (x_{n} + y_{n}) \le \overline{\lim_\limits{n\to\infty}} x_{n} + \overline{\lim_\limits{n\to\infty}} y_{n}$  

для нижнего предела АНАЛогично, но знак неравенства в другую сторону ($\varliminf_\limits{n\to\infty} (x_{n} + y_{n}) \ge \varliminf_\limits{n\to\infty} x_{n} + \varliminf_\limits{n\to\infty} y_{n}$)


## Умножение на константу
**Формулировка** $\forall \lambda > 0: \overline{\lim_\limits{n\to\infty}} \lambda x_{n} = \lambda \overline{\lim_\limits{n\to\infty}} \ x_{n}$  
доказательство:
по свойству $\sup$ мы можем:
$\forall \lambda > 0: \overline{\lim_\limits{n\to\infty}} \lambda x_{n} = \lim_\limits{k\to\infty} \sup_\limits{n\ge k}\{\lambda x_{n}\} = \lim_\limits{k\to\infty} \lambda\sup_\limits{n\ge k}\{x_{n}\}$ 
по свойству предела
$\lim_\limits{k\to\infty} \lambda\sup_\limits{n\ge k}\{x_{n}\} = \lambda \lim_\limits{k\to\infty} \sup_\limits{n\ge k}\{x_{n}\} = \lambda \overline{\lim_\limits{n\to\infty}} \ x_{n}$ 

# Умножение пределов
**Формулировка** $\forall n: x_{n}, y_{n} \ge n \quad \overline{\lim_\limits{n\to\infty}} (x_{n} y_{n}) \le \overline{\lim_\limits{n\to\infty}} x_{n} \overline{\lim_\limits{n\to\infty}} y_{n}$ 

для нижнего предела АНАЛогично, но $\varliminf_\limits{n\to\infty} (x_{n}  y_{n}) \ge \varliminf_\limits{n\to\infty} x_{n} \varliminf_\limits{n\to\infty} y_{n}$
$\forall k \newline \forall n \ge k \quad x_{n} \le \sup_\limits{m\ge k} x_{m} \newline \forall n \ge k \quad y_{n} \le \sup_\limits{m\ge k} y_{m}$  

$x_{n}y_{n} \le \sup_\limits{m\ge k} x_{m} \sup_\limits{m\ge k} y_{m}$
по св-ву супремума
$\sup_\limits{n\ge k} x_{n} y_{n} \le \sup_\limits{m\ge k} x_{m} \sup_\limits{m\ge k} y_{m}$ 
предельный переход
$\lim_\limits{k\to\infty} \sup_\limits{n\ge k} x_{n} y_{n} \le \lim_\limits{k\to\infty}  \sup_\limits{m\ge k} x_{m} \lim_\limits{k\to\infty} \sup_\limits{m\ge k} y_{m}$ 
из определения верхнего предела
$\overline{\lim_\limits{n\to\infty}} (x_{n} y_{n}) \le \overline{\lim_\limits{n\to\infty}} x_{n} \overline{\lim_\limits{n\to\infty}} y_{n}$ 

## Свойство изменения знака (или инверсии) для верхнего и нижнего пределов
**Формулировка** $\overline{\lim_\limits{n\to\infty}} (-x_{n}) = -\varliminf_\limits{n\to\infty} x_{n}$   
Доказательство: 
Воспользуемся следующим фактом:
$\sup -A =- \inf A$ 
$\overline{\lim_\limits{n\to \infty} (-x_{n})} =\lim_\limits{n\to \infty} \sup\{-x_{k}| k \ge n\} = \lim_\limits{n\to \infty} -\inf\{x_{k}| k \ge n\} = - \lim_\limits{n\to \infty} \inf\{x_{k}| k \ge n\} =-\varliminf_\limits{n\to\infty} x_{n}$
