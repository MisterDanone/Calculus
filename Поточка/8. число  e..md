$\sum\limits_{k=0}^{n}C_{n}^{k} (\frac{1}{n})^{k} = \sum\limits_{k=0}^{n}C_{n}^{k} \frac{1}{n^{k}} = \sum\limits_{k=0}^{n} \frac{n!}{k!(n-k)!}\frac{1}{n^{k}} = 2 +\sum\limits_{k=2}^{n}\frac{n!}{k!(n-k)!}\frac{1}{n^{k}} \newline$   Разделим на $(n-k)!$  (мы получили 2 +, путём того, что подставили k = 0, k = 1 в выражение)
$2 + \sum\limits_{k=2}^{n} \frac{n \dots (n - k +1)}{k!} \frac{1}{n^{k}} = 2 +\sum\limits_{k=2}^{n} \frac{1 (1 - \frac{1}{n})\dots\left(1 - \frac{k-1}{n}\right)(**)}{k!} (*)$ 
оценим сумму обозначенную ($**$)
$1 (1 - \frac{1}{n}) \dots  (1 - \frac{k-1}{n})$, мы отнимаем из каждой единицы число. т.е. получается произведение чисел лежащих в промежутке $(0;1)$, соответственно и их сумма лежит в этом промежутке
вернёмся к ($*$)
$2 +\sum\limits_{k=2}^{n} \frac{1 (1 - \frac{1}{n})\dots\left(1 - \frac{k-1}{n}\right)}{k!} \le 2 +\sum\limits_{k=2}^{n} \frac{1}{k!} \le 2 +\sum\limits_{k=2}^{n} \frac{1}{2^{k-1}} = \newline= 2 + \frac{1}{2} + \frac{1}{4} + \dots + \frac{1}{2^{n-1}} = 2 + \frac{ \frac{1}{2}(1 - \frac{1}{2}^{n-1})}{1- \frac{1}{2}} = 3 - \frac{1}{2^{n-1}} < 3 \quad \forall n$  
т.е. наша последовательность ограничена
докажем,что она возрастает
$\forall n: x_{n} < x_{n+1}$

$\sum\limits_{k=2}^{n} \frac{n!}{k!(n-k)!} \frac{1}{n^{k}} < \sum\limits_{k=2}^{n+1} \frac{(n+1)!}{k!(n+1-k)!} \frac{1}{(n+1)^{k}}$ 
$\sum\limits_{k=2}^{n} \frac{n \dots (n-k+1)}{k!} \frac{1}{n^{k}}< \sum\limits_{k=2}^{n+1} \frac{(n+1) \dots (n + 2 -k)}{k!} \frac{1}{(n+1)^{k}}$

## вспомогательное утверждение
обозначим $1 (1 - \frac{1}{n}) \dots \left(1 - \frac{k-1}{n}\right)= C n,k$  не путать с $C_{n}^k$
докажем, что $\lim_\limits{n\to \infty} C n,k = 1$
$(2 \le k \le n, C n, 1 = 1 = C n, 0)$ 
математическая индукция
(для того чтобы не мозолить глаз в этом доказательстве будет $C n,t$)
1)$t = 1$
$C n,1 = 1$
очевидно
2)$t = k$
$C n,k = 1 (1 - \frac{1}{n}) \dots \left(1 - \frac{k-1}{n}\right)= C n,k$ по обозначению
$\lim_\limits{n\to \infty} C n,k = 1$
3)$t = k+1$
$C n+1,k = C n,k (1 - \frac{k}{n})$ 
т.к. $\lim_\limits{n\to \infty} C n,k = 1$ и $\lim_\limits{n\to \infty} 1 - \frac{k}{n} = 1$,
то следовательно утверждение верно

## доказательство
Докажем, что $e = \lim_\limits{n \to \infty} \sum\limits_{k=0}^{n} \frac{1}{k!}$ , докажем, что $\lim_\limits{{n}\to \infty} \sum\limits_{k=0}^{n} \frac{1}{k!} - (1+\frac{1}{n})^{n} = 0$,
обозначим $y_{n} = (1+ \frac{1}{n})^{n}, \quad x_{n} = \sum\limits_{k=0}^{n} \frac{1}{k!}$, $\ \forall n \ y_{n} < x_n$ 
по определенению предела
$\forall \varepsilon > 0 \ \exists N: \forall n > N \quad |y_{n} - x_{n}| < \varepsilon$ 
будем считать, что $0 < \varepsilon < 4$
обозначим $1 (1 - \frac{1}{n}) \dots \left(1 - \frac{k-1}{n}\right)= C n,k$  не путать с $C_{n}^k$ 
(получение $C n,k$ в начале док-ва)

 $y_{n} = \sum\limits_{k=0}^{n} C n,k \frac{1}{k!}$ 
 $|y_{n}- x_{n}| < |\sum\limits_{k=0}^{n} C n,k \frac{1}{k!} - \sum\limits_{k=0}^{n} \frac{1}{k!}| = |2 +\sum\limits_{k=2}^{n} C n,k \frac{1}{k!} - 2 -\sum\limits_{k=2}^{n} \frac{1}{k!}|$ 
 зафиксируем $\gamma \in \mathbb{N}$ 
 $|\sum\limits_{k=2}^{\gamma-1} C n,k \frac{1}{k!} - \sum\limits_{k=2}^{\gamma-1} \frac{1}{k!} + \sum\limits_{k=\gamma}^{n} C n,k \frac{1}{k!} - \sum\limits_{k=\gamma}^{n} \frac{1}{k!}|$  неравенство треугольника [[Очевидные вещи из доказательств#неравенство треугольника]]
 $|\sum\limits_{k=2}^{\gamma-1} C n,k \frac{1}{k!} - \sum\limits_{k=2}^{\gamma-1} \frac{1}{k!} + \sum\limits_{k=\gamma}^{n} C n,k \frac{1}{k!} - \sum\limits_{k=\gamma}^{n} \frac{1}{k!}| \le|\sum\limits_{k=2}^{\gamma-1} C n,k \frac{1}{k!} - \sum\limits_{k=2}^{\gamma-1} \frac{1}{k!}| +| \sum\limits_{k=\gamma}^{n} C n,k \frac{1}{k!} - \sum\limits_{k=\gamma}^{n} \frac{1}{k!}| (***)$  
$|\sum\limits_{k=2}^{\gamma-1} C n,k \frac{1}{k!} - \sum\limits_{k=2}^{\gamma-1} \frac{1}{k!}| +| \sum\limits_{k=\gamma}^{n} C n,k \frac{1}{k!} - \sum\limits_{k=\gamma}^{n} \frac{1}{k!}| = \sum\limits_{k=2}^{\gamma-1}(1 - C n,k) \frac{1}{k!} + \sum\limits_{k = \gamma}^{n}(1- C n,k) \frac{1}{k!}$  
оценим 2 слагаемое
$\sum\limits_{k=\gamma}^{n} (1 - Cn,k) \frac{1}{k!} < \sum\limits_{k = \gamma}^{n} \frac{1}{k!} = \frac{1}{\gamma!} + \dots + \frac{1}{n!} = \frac{1}{\gamma!}\left(1 + \frac{1}{\gamma+1} + \dots + \frac{1}{(\gamma+1)\dots(n)}\right) <\frac{1}{\gamma!}\left(1 + \frac{1}{\gamma+1} + \frac{1}{(\gamma+1)^{2}} + \dots + \frac{1}{(y+1)^{n-\gamma}}\right)= \frac{1}{\gamma!} \frac{1*(1- \frac{1}{(\gamma+1)^{n-\gamma}})}{1- \frac{1}{\gamma+1}} < \frac{2}{\gamma} < \frac{\varepsilon}{2}$
т.к. $\gamma$ фиксированное, то для первого слагаемого найдём  $N: \forall n > N \quad 1 - C n,k < \frac{\varepsilon}{2\gamma}$ для всех $k = 2,3,4,\dots,\gamma -1$ то есть
$\sum\limits_{k=2}^{\gamma-1}(1 - C n,k) \frac{1}{k!} <\sum\limits_{k=2}^{\gamma-1} \frac{\varepsilon}{2\gamma} \frac{1}{k!} \le \frac{\varepsilon}{2}$
