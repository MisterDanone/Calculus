
# Предел последовательности
*Опр.* Число $A$ называется пределом последовательности {$x_{n}$}, если $\forall \varepsilon > 0 \ \exists N_{\varepsilon}: \forall n > N_{\varepsilon}: \quad |x_{n} - A| < \varepsilon$ 

# Арифметика пределов
Работает только на конечных пределах
## Сложение/Вычитание пределов
Если $\lim_\limits{n \to \infty}x_n = a \in \mathbb{R}$, и $\lim_\limits{n \to \infty} y_n = b \in \mathbb{R}$, тогда $\lim_\limits{n \to \infty} x_n \pm y_n = a \pm b$
Доказательство:
сложение:
	 $\lim_\limits{n \to \infty}x_n = a \in \mathbb{R}$, и $\lim_\limits{n \to \infty} y_n = b \in \mathbb{R}$
	возьмём произвольный $\varepsilon = \frac{\varepsilon}{2}$,
	$\exists N_1: \forall n > N_1 \quad |x_n - a| < \varepsilon$ 
	$\exists N_2: \forall n > N_2 \quad |y_n - b| < \varepsilon$ 
	возьмём $N = max{N_1, N_2}$, р-м
	$|(x_n +y_n) - (a + b)| =|(x_n-a)+(y_n-b)| \le |x_n - a| + |y_n - b| <  \frac{\varepsilon}{2} +  \frac{\varepsilon}{2} = \varepsilon$ 
	
вычитание:
	 $\lim_\limits{n \to \infty}x_n = a \in \mathbb{R}$, и $\lim_\limits{n \to \infty} y_n = b \in \mathbb{R}$
	возьмём произвольный $\varepsilon = \frac{\varepsilon}{2}$,
	$\exists N_1: \forall n > N_1 \quad |x_n - a| < \varepsilon$ 
	$\exists N_2: \forall n > N_2 \quad |y_n - b| < \varepsilon$ 
	возьмём $N = max{N_1, N_2}$, р-м
	$|(x_n - a) - (y_n - b)| \le |x_n - a| - |y_n - b| \le |x_n - a| + |y_n - b| < \frac{\varepsilon}{2} +  \frac{\varepsilon}{2} = \varepsilon$ 
## Умножение/Деление
Если $\lim_\limits{n \to \infty}x_n = a \in \mathbb{R}$, и $\lim_\limits{n \to \infty} y_n = b \in \mathbb{R}$, тогда $\lim_\limits{n \to \infty} x_n y_n = a b$
Доказательство:
	пусть  $\lim_\limits{n \to \infty}x_n = a \in \mathbb{R}$, , и $\lim_\limits{n \to \infty} y_n = b \in \mathbb{R}$
	т.к. $x_n$ - сходящаяся последовательность, следовательно она ограничена ([[3.Предел последовательности. Единственность предела. Ограниченность сходящейся последовательности.#Ограниченность сходящейся последовательности]]), другими словами, $\exists M > 0 \ \forall n: |x_n| < M$ 
	для каждой из последовательностей выберем произвольный $\varepsilon > 0$
	$\exists N_1: \ \forall n > N_1 \quad |x_n - a| < \frac{\varepsilon}{2|b|}$
	$\exists N_2: \ \forall n > N_2 \quad |y_n - b| < \frac{\varepsilon}{2M}$
	р-м
	$|x_n y_n - ab| = |x_n y_n - ab + 0| = | x_n y_n - ab +x_n b - x_n b| = \newline = |x_n(y_n - b) + b(x_n - a)| \le |x_n(y_n -b)| + |b(x_n - a)| = \newline= |x_n||y_n - b| + |b||x_n - a| \le |M||y_n - b| + |b||x_n -a| = \newline= |M| \frac{\varepsilon}{2M} + |b|\frac{\varepsilon}{2|b|} = \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon$, что и требовалось доказать
$\lim_\limits{n \to \infty}x_n = a \in \mathbb{R}$, и $\lim_\limits{n \to \infty} y_n = b \in \mathbb{R} \textbackslash\{0\}$, тогда $\lim_\limits{n \to \infty} \frac{x_n}{y_n} = \frac{a}{b}$
Доказательство:
	пусть  $\lim_\limits{n \to \infty}x_n = a \in \mathbb{R}$, , и $\lim_\limits{n \to \infty} y_n = b \in \mathbb{R}$
	($*$) Вспомогательное утверждение, если $\lim_\limits{n \to \infty} = a$, то $\lim_\limits{n \to \infty} |x_n| = |a|$
	$\forall \varepsilon > 0 \ \exists N_{\varepsilon}: \ \forall n > N_{\varepsilon} \quad |x_n - a| < \varepsilon$ 
		$||x_n| - |a|| \le |x_n - a| \le \varepsilon$ 
		по определению предела $\exists \lim_\limits{n \to \infty} |x_n| = |a|$
	
Докажем, что $\lim_\limits{n \to \infty} \frac{1}{y_n} = \frac{1}{b}, b \in \mathbb{R} \backslash \{0\}$
	р-м $|\frac{1}{y_n} - \frac{1}{b}| = |\frac{b-y_n}{b y_n}| = |\frac{y_n - b}{b y_n}| = \frac{|y_n - b|}{|b y_n|}$
	$\exists N_1 \ \forall n > N_1 \quad \lim_\limits{n \to \infty} |y_n| = |b| > \frac{|b|}{2} > 0$, т.к. $b \in \mathbb{R} \backslash \{0\}$, 
	$\exists N_2: \forall n > N_2 \quad |y_n - b| <\varepsilon \frac{b^2}{2}$ 
	$N = max{N_1, N_2}$
	$|\frac{1}{y_n} - \frac{1}{b}| = \frac{|y_n - b|}{|b y_n|} < \frac{\varepsilon \frac{b^2}{2}}{\frac{|b|}{2} |b|} < \varepsilon$
